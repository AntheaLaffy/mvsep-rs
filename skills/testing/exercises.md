# 练习：测试

对应课程第 9 讲的练习（节选，按主题归入本 skill），复习用。

1. **单元测试 + 覆盖率**。学一种你熟悉语言的测试库，为你在做的项目写一个单元测试。运行代码覆盖率工具，生成 HTML 格式的覆盖率报告并观察——哪些行被覆盖了？你的覆盖率很可能会很低，手动写些测试改进它。再试着用一个 AI agent 提高覆盖率：确保它能以带覆盖率的方式运行测试、拿到逐行覆盖率报告，这样它才知道该聚焦哪里。AI 生成的测试真的好吗？
