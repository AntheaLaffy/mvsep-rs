# 练习：代码评审

对应课程 Collaboration 一讲的练习，复习用。

1. **通读一次真实评审。** 找一个你熟悉项目里已经合并的 PR，其中包含实质性的评审意见（不只是「LGTM」）。通读整个评审。所有评论同样高效吗？如果你是 PR 作者，收到这些评论的体验会如何？
