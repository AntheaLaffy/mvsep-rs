# 练习：代码质量工具

对应课程第 9 讲的练习（节选，按主题归入本 skill），复习用。

1. **配齐格式化、linter 与 pre-commit**。为你在做的项目配置格式化器、linter 和 pre-commit 钩子。错误很多时：格式化错误交给自动格式化；linter 错误试着用一个 AI agent 来修——确保它能自己跑 linter 并观察结果，在迭代循环里修完所有问题。仔细检查结果，确保 AI 没有破坏你的代码！
